# Price Action Desk

โต๊ะวิเคราะห์ทองคำ XAU/USD และคู่เงิน EUR/USD, GBP/USD ภาษาไทย พร้อมกราฟแท่ง แนวรับ–แนวต้าน สัญญาณตามกฎ และเครื่องคำนวณล็อตสำหรับบัญชี USD ใช้ศึกษาหรือเทรดกระดาษ โปรแกรมไม่มีคำสั่งส่งออเดอร์ไปโบรกเกอร์

## เปิดใช้งาน

ใช้ Python 3.11 ขึ้นไป หน้าเว็บใช้ไลบรารีมาตรฐานของ Python บน Mac ดับเบิลคลิก **Open Price Action Desk.command** ในโฟลเดอร์โปรเจกต์ได้ หรือรันคำสั่งต่อไปนี้

```sh
git clone https://github.com/tanawatprasittimay-afk/price-action-desk.git
cd price-action-desk
python3 app.py --open
```

- เปิด [หน้าเว็บในเครื่อง](http://127.0.0.1:8765) โปรแกรมสร้างรหัสผ่านสุ่มเฉพาะเครื่องไว้ที่ `~/.config/price-action-desk/password.txt` ตอนรันครั้งแรก และพิมพ์ตำแหน่งไฟล์ในเทอร์มินัล หากต้องการกำหนดเอง ตั้งตัวแปรสภาพแวดล้อม `PRICE_DESK_PASSWORD` อย่างน้อย 16 ตัวอักษรก่อนเปิดโปรแกรม
- บน Windows ใช้ `py -3 app.py --open` และติดตั้งฐานข้อมูลเขตเวลาด้วย `py -3 -m pip install tzdata` ไฟล์รหัสผ่านอยู่ในโฟลเดอร์ผู้ใช้ใต้ `.config/price-action-desk`
- เซสชันเว็บมีอายุ 8 ชั่วโมง โหมดเริ่มต้นรับการเชื่อมต่อจากเครื่องที่รันเท่านั้น คนอื่นดาวน์โหลดโค้ดแล้วใช้งานพร้อมรหัสของตัวเอง
- กด **เปิดแจ้งเตือน** และอนุญาตในเบราว์เซอร์ เปิดหน้าเว็บและเครื่องไว้ ระบบตรวจทุก 60 วินาทีสำหรับคู่และกรอบเวลาที่เลือก จะแจ้ง BUY/SELL เมื่อพบแท่งปิดใหม่ต่อเนื่องที่เข้าเงื่อนไขในโหมดข้อมูลตลาดจริง การพักเครื่อง ปิดแท็บ หรือเบราว์เซอร์ชะลอการทำงานเบื้องหลังอาจทำให้พลาดการแจ้งเตือน

## เปิดบน iPhone โดยใช้ Mac เป็นเครื่องหลัก

Mac ต้องตื่น เชื่อมต่ออินเทอร์เน็ตสำหรับราคาตลาดจริง และเปิดโปรแกรมอยู่ ล็อก Mac หรือดับจอได้ ทุกเส้นทางใช้รหัสผ่านของ Price Action Desk บน Mac แต่ละเครื่องติดตั้งโปรแกรมจาก GitHub แล้วสร้างรหัสของตัวเองได้ตามปกติ

**Wi-Fi ในบ้าน**

1. ต่อ iPhone เข้ากับเครือข่ายบ้านเดียวกับ Mac (Mac ต่อสาย Ethernet ได้) แล้วดับเบิลคลิก **Connect iPhone on Wi-Fi.command** บน Mac
2. ครั้งแรก ใช้ Finder กด Command-Shift-G แล้วเปิดโฟลเดอร์ `~/.config/price-action-desk/iphone-share/` จากนั้น AirDrop ไฟล์สาธารณะ `Price Action Desk LAN Root.cer` จาก Mac ของคุณไปยัง iPhone ส่วนตัว เลือกติดตั้งโปรไฟล์จากการตั้งค่า แล้วไปที่ **ทั่วไป → เกี่ยวกับ → การตั้งค่าความเชื่อถือใบรับรอง** เพื่อเปิดความเชื่อถือสำหรับ **Price Action Desk LAN Root** ให้เก็บไฟล์ที่ลงท้ายด้วย `.key` ไว้เฉพาะบน Mac [วิธีตรวจความเชื่อถือบน iOS](https://support.apple.com/en-us/102390)
3. เปิดลิงก์ HTTPS ที่ Terminal แสดงใน Safari แล้วใส่รหัสผ่านแอป หากชื่อที่ลงท้ายด้วย `.local` เปิดไม่ได้ ลองลิงก์ IP ที่แสดงด้วยกัน Wi-Fi สำหรับแขกบางระบบแยกอุปกรณ์ออกจากกัน หลัง Mac เปลี่ยน IP ให้เปิดตัวเชื่อมใหม่เพื่อออกใบรับรองสำหรับที่อยู่ปัจจุบัน
4. ใน Safari แตะ **แชร์ → เพิ่มไปยังหน้าจอโฮม** เพื่อเปิดกราฟจากไอคอนได้ครั้งถัดไป

**นอกบ้านผ่าน 5G หรือ Wi-Fi อื่น**

1. ติดตั้ง Tailscale บน Mac และ iPhone ทำตามหน้าจอลงชื่อเข้าใช้ด้วยบัญชีส่วนตัวเดียวกัน และอนุญาต VPN บนอุปกรณ์ทั้งสอง [Mac](https://tailscale.com/docs/install/mac) · [iPhone](https://tailscale.com/docs/install/ios)
2. บน Mac ดับเบิลคลิก **Connect iPhone over VPN.command** เปิดหน้าต่าง Terminal นั้นค้างไว้ หาก Tailscale ให้เปิด HTTPS ให้ตรวจรายละเอียดและยืนยันในบัญชีของคุณ ตัวเชื่อมใช้ Tailscale Serve ภายในเครือข่ายส่วนตัว เลือกพอร์ตว่าง และใช้ใบรับรอง HTTPS ของ Tailscale โดยไม่ต้องติดตั้งใบรับรอง Wi-Fi ข้างต้น [Tailscale Serve](https://tailscale.com/docs/features/tailscale-serve)
3. ปิด Wi-Fi บน iPhone เพื่อทดสอบผ่าน 5G เปิด Tailscale ให้เชื่อมต่อ แล้วเปิดลิงก์ HTTPS ที่ตัวเชื่อมแสดงหลังรายงานว่าพร้อมใน Safari เข้าระบบ เปิดกราฟ และลองคำนวณล็อต พอร์ตเริ่มต้นคือ 18765 ตัวเชื่อมจะเลือกพอร์ตถัดไปหากพอร์ตเดิมมีบริการอื่นใช้อยู่
4. หยุดการแชร์ผ่าน VPN โดยกด Control-C ในหน้าต่างตัวเชื่อม โหมดใช้งานบน Mac เดิมเปิดแยกได้ทั้งสองกรณี รุ่นนี้ตรวจสัญญาณขณะหน้าเว็บทำงาน การส่งสัญญาณไปยังหน้าจอล็อกยังต้องเพิ่มบริการ Web Push

**ให้สมาชิกครอบครัวที่อยู่คนละบ้านใช้** ให้แต่ละคนใช้บัญชี Tailscale ของตัวเอง เจ้าของ Mac สามารถเชิญแชร์เครื่องผ่านลิงก์ใช้ครั้งเดียวหรืออีเมลและถอนสิทธิ์ภายหลัง ควรจำกัดนโยบายเครือข่ายให้เข้าถึงเฉพาะพอร์ตแอปก่อนเชิญ ขณะนี้ Price Action Desk มีรหัสผ่านเจ้าของชุดเดียว หากต้องการรหัสและการถอนสิทธิ์ในตัวแอปแยกตามคนจะต้องเพิ่มบัญชีผู้ใช้ [การแชร์เครื่องและถอนสิทธิ์](https://tailscale.com/docs/features/sharing)

## เลือกข้อมูลก่อนอ่านสัญญาณ

| โหมด | เหมาะสำหรับ | สิ่งที่ต้องมี |
| --- | --- | --- |
| ข้อมูลจำลอง | ฝึกอ่านกราฟและลองเครื่องคิดล็อต | ใช้งานได้ทันที ราคาสร้างซ้ำได้ด้วย seed เฉพาะคู่และกรอบเวลา |
| ข้อมูลตลาดจริง | อ่านแท่งปิด 15 นาที, 1 ชั่วโมง, 4 ชั่วโมง หรือรายวัน | Twelve Data มีช่องทดลองสาธารณะสำหรับ EUR/USD ส่วน XAU/USD และ GBP/USD ต้องมีคีย์ที่มีสิทธิ์ของผู้ใช้ |
| CSV / MT5 | ทดสอบประวัติราคาของโบรกเกอร์ที่ใช้จริง | เลือกสินทรัพย์ กรอบเวลา เขตเวลาของเครื่องเซิร์ฟเวอร์ MT5 แล้วเลือกไฟล์แท่งย้อนหลัง |

กำหนด `TWELVE_DATA_API_KEY` เป็นตัวแปรสภาพแวดล้อมของโปรแกรมที่เรียกข้อมูล แล้วเปิดโปรแกรมใหม่ คีย์อยู่ฝั่ง Python หน้าเว็บและ GitHub ไม่ต้องรับคีย์ ช่องทดลองอาจติดโควตาหรือมีความล่าช้า ราคา Twelve Data เป็นราคาอ้างอิงจากหลายแหล่ง ราคาซื้อขายจริงและเวลาทำการของ Axi หรือโบรกเกอร์อื่นอาจต่างกัน [เอกสารแหล่งราคา](https://support.twelvedata.com/en/articles/12520817-forex-api-v2)

ข้อมูลตลาดจริงจะตัดแท่งที่ทับช่วงปิดสุดสัปดาห์ออกทั้งแท่งตามเวลานิวยอร์กและฤดูของสหรัฐฯ สำหรับ 4 ชั่วโมงและรายวัน ระบบรวมราคา 1 ชั่วโมงเป็นช่วง UTC ที่มีข้อมูลครบ และคงช่องว่างไว้เมื่อแท่งขาด ช่วงข่าว วันหยุดพิเศษ และช่วงพักระหว่างวันยังต้องเทียบกับตารางของโบรกเกอร์ [เวลาซื้อขายที่ใช้อ้างอิง](https://www.oanda.com/bvi-en/cfds/hours-of-operation/)

ไฟล์นำเข้ารองรับ 35–3,000 แท่ง สูงสุด 1 MB เช่น CSV หัวตาราง `time,open,high,low,close` หรือไฟล์ Bars แบบคั่นแท็บจาก MT5 ที่มี DATE, TIME, OPEN, HIGH, LOW, CLOSE ใช้เวลาเปิดแท่งเป็น Unix วินาทีหรือ ISO 8601 ที่มี UTC offset ได้ หากไม่มี offset ให้เลือกเขตเวลาตามต้นทาง โปรแกรมประมวลผลเฉพาะแท่งปิดในเครื่อง ไฟล์ที่มีช่วงเปลี่ยนนาฬิกาและเวลาท้องถิ่นกำกวมควรแปลงเป็น UTC ก่อน

## ตีความกราฟ

- **แนวรับและแนวต้าน** เกิดจากจุดสูงหรือต่ำที่มีแท่งปิดยืนยันข้างละสองแท่ง ภายในช่วงย้อนหลัง 160 แท่ง ระบบรวมจุดที่ใกล้กันตาม ATR แสดงราคาและจำนวนครั้งที่พบ จุดที่เพิ่งเกิดต้องรอการยืนยันก่อนนำมาใช้
- **BUY/SELL/WAIT** ประเมินรูปแบบแท่ง เช่น engulfing, pin bar, breakout, inside bar และ doji ร่วมกับ EMA 12/26, MACD 12/26/9 และ Wilder RSI 14 ฝั่ง BUY ต้องมี PA ขาขึ้น EMA เร็วอยู่เหนือ EMA ช้า histogram เป็นบวก และ RSI ตั้งแต่ 50 ถึงต่ำกว่า 70 ฝั่ง SELL ใช้เงื่อนไขกลับทิศและ RSI มากกว่า 30 ถึง 50 ต้องมีพื้นที่ถึงแนวฝั่งตรงข้ามอย่างน้อย 2R สุทธิเมื่อประเมินด้วยต้นทุนที่ตั้งไว้
- **ขนาดสถานะ** ใช้ทุน เปอร์เซ็นต์เสี่ยง ระยะจุดตัดขาดทุน ต้นทุน ขนาดสัญญา และมาร์จิน ปัดล็อตลง คืน 0 เมื่อเงินเสี่ยงไม่พอสำหรับขั้นต่ำ สมมติฐานมาตรฐานคือทอง 100 ออนซ์ต่อ lot และ Forex 100,000 หน่วยต่อ lot ผู้ใช้แก้ได้ตามสเปกบัญชี หากราคากระโดดข้าม stop ขาดทุนจริงอาจสูงกว่าที่ประมาณไว้ [สัญญาทอง Axi](https://www.axi.com/int/trade/cfds/commodities/precious-metals/gold) · [ขนาดล็อต Forex ของ Axi](https://fcasupport.axi.com/en-GB/axifca--axicorp-prod/article/nBCZo2_O-can-i-trade-micro-and-mini-lots-with-axi)
- **ผลย้อนหลัง** ราคาเข้าเร็วสุดคือเปิดแท่งถัดไป และจะทวนเงื่อนไข 2R อีกครั้งเมื่อราคาเปิดเปลี่ยน ถือได้ทีละหนึ่งสถานะ หากแตะทั้งเป้าหมายและ stop ในแท่งเดียว ใช้ฝั่งขาดทุนก่อน นับรายการยังไม่ปิดแยกจากอัตราชนะ ค่าเฉลี่ยกำไร/ขาดทุนและการลดลงจากจุดสูงสุดคิดเป็น R โดย 1R คือเงินที่เสี่ยงตามแบบจำลองต่อไม้
- ต้นทุนตั้งต้นของสัญญาณและผลย้อนหลังคือสเปรดเต็ม 2 bps, slippage 0.25 bps ต่อข้าง และค่าธรรมเนียม 0 โดย 1 bp = 0.01% แบบจำลองใช้ราคากลางเมื่อคำนวณต้นทุน แม้ไฟล์ MT5 มักเก็บ Bid จึงไม่สามารถจำลอง tick, สเปรดแปรผัน หรือค่าสวอปได้ เครื่องคำนวณล็อตปรับสมมติฐานต้นทุนแยกได้

## ใช้กับ Claude Code หรือ Codex

สกิล [FX Price Action Review](skills/fx-price-action-review/SKILL.md) มี [5 prompt ภาษาไทย](skills/fx-price-action-review/references/prompts-th.md) สำหรับอ่านข่าว วิเคราะห์ BUY/SELL ตรวจล็อต และเปรียบเทียบผลย้อนหลัง คัดลอกโฟลเดอร์สกิลไว้ในไดเรกทอรี skills ของแอปที่ใช้

ตัวเชื่อม MCP ทำงานผ่าน stdio ในเครื่องและใช้สูตรเดียวกับเว็บ ติดตั้ง [uv](https://docs.astral.sh/uv/getting-started/installation/) แล้วรันบรรทัดของแอปที่ใช้จากโฟลเดอร์โปรเจกต์ บน Windows ให้แทนที่เส้นทางด้วยตำแหน่งเต็มของ uv และ mcp_server.py

```sh
claude mcp add --scope user price-action-desk -- "$(command -v uv)" run --script "$PWD/mcp_server.py"
codex mcp add price-action-desk -- "$(command -v uv)" run --script "$PWD/mcp_server.py"
```

เริ่มแชตใหม่แล้วเรียกสกิลด้วยชื่อ `fx-price-action-review` ตัวเชื่อมมีสามเครื่องมือสำหรับผู้ใช้เครื่องนั้นเอง

| เครื่องมือ | สิ่งที่ได้ |
| --- | --- |
| market_report | ราคาปิดล่าสุด แท่งล่าสุดแปดแท่ง แนวรับ/ต้านที่รู้ได้ก่อนแต่ละแท่ง RSI/MACD คำตัดสินและเหตุผล ระบุ live หรือ demo |
| calculate_lots | ล็อต มาร์จิน ผลขาดทุนตาม stop และเป้ากำไรสุทธิจากสมมติฐานที่ระบุ |
| evaluate_strategy | อุ่นตัวชี้วัดด้วย 70% แรก วัด 30% หลัง เปรียบเทียบกฎ PA กับ EMA 20/50 ผ่านแบบจำลองการเข้าซื้อขายและต้นทุนเดียวกัน |

อัตราชนะที่มีจำนวนเทรดน้อยยังใช้สรุปความแม่นยำไม่ได้ และเมื่อไม่มีเทรดก็ไม่มีอัตราชนะให้รายงาน รายงานสาธารณะของ [StockBench](https://arxiv.org/abs/2510.02209) เป็นการทดลองกับหุ้น การนำกฎมาใช้กับทองหรือ Forex ต้องทดสอบแยก
