# 5 คำสั่งสำหรับฝึกกับ Claude หรือ Codex

ตัวอย่างเหล่านี้ใช้ศึกษาการตัดสินใจ ยังไม่มีหลักฐานว่าทำกำไรได้ต่อเนื่อง ใช้ตัวเลขจากเครื่องมือหรือข้อมูลที่ให้มา ระบุเวลาพร้อมเขตเวลา และบอกเมื่อข้อมูลไม่พอ

1. **อ่านข่าวทอง** — “อ่านเฉพาะพาดหัวและเวลาเผยแพร่ที่ฉันแนบ แยกข้อเท็จจริงออกจากการตีความ เขียนว่าข่าวนี้อาจกระทบ XAU/USD ทางใดและเพราะอะไร ถ้าหลักฐานรองรับได้ทั้งสองทาง ให้ตอบว่ายังสรุปทิศไม่ได้” แนวคิดการแยกข้อมูลจากพาดหัวข่าวมีตัวอย่างในงานวิจัยหุ้นของ [Lopez-Lira และ Tang](https://papers.ssrn.com/sol3/papers.cfm?abstract_id=4412788)
2. **หา BUY ใกล้แนวรับ** — “อ่าน XAU/USD H1 จากแท่งที่ปิดแล้ว บอกแหล่งราคาและเวลา ระบุแนวรับที่ยืนยันแล้ว ราคาและจำนวนครั้งที่แตะ ตรวจ PA, RSI และ MACD ถ้าแท่งปฏิเสธแนวรับและยังเหลือที่ถึงแนวต้าน ประเมินราคาเข้า จุดตัดขาดทุน และเป้าหมาย ถ้ากำไรหลังต้นทุนต่ำกว่า 2 เท่าของเงินเสี่ยงหรือไม่มีข้อมูลสด ให้ตอบ WAIT”
3. **หา SELL หลังทะลุแนวต้านแล้วกลับลงมา** — “ตรวจ EUR/USD M15 ให้ใช้เฉพาะแนวต้านที่รู้ก่อนแท่งนั้น ตรวจว่าราคาสูงสุดข้ามโซนแล้วปิดกลับลงมาต่ำกว่าโซนหรือยัง บอกเวลาแท่ง ราคา จุดที่แผนผิด และแนวรับถัดไป ถ้าไม่เห็นเหตุการณ์ให้ตอบ WAIT กฎนี้เป็นสมมติฐานใหม่ แยกผลจากกลยุทธ์หลัก”
4. **ค้านแผนและคำนวณล็อต** — “ตรวจแผนสมมติ XAU/USD ทุน 10,000 USD เสี่ยง 1% เข้า 2,050 หยุด 2,045 สัญญา 100 ออนซ์ต่อ lot ขั้นต่ำและขั้นล็อต 0.01 ใช้ leverage 100 และเป้าสุทธิ 2R ระบุสมมติฐานสเปรด ค่าธรรมเนียม และ slippage คำนวณล็อตที่ปัดลง ขาดทุนตามแบบจำลองและเป้าหมาย บอกข้อมูลที่ยังขาดก่อนตัดสินใจเข้า”
5. **ตรวจว่าได้เปรียบจริงไหม** — “ใช้ evaluate_strategy กับ EUR/USD H1 โหมด live ล็อกกฎไว้ล่วงหน้า ใช้ข้อมูล 70% แรกอุ่นเครื่อง แล้ววัด 30% หลัง เทียบกับ EMA 20/50 ด้วยต้นทุนและกฎจำลองการเข้าออกชุดเดียวกัน แสดงจำนวนเทรด ชนะ แพ้ กำไรสุทธิเฉลี่ยต่อไม้ และการลดลงจากจุดสูงสุดเป็น R ถ้าตัวอย่างน้อยให้บอกว่ายังสรุปไม่ได้ และแยกผลทดสอบออกจากกำไรเงินจริง”
